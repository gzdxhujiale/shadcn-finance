# shadcn-finance

A modern finance dashboard built with Vue 3, Vite, and Shadcn Vue.

## Features

- **Vue 3 + Vite**: Lightning fast build and HMR.
- **Shadcn Vue**: Beautiful, accessible, and customizable components.
- **Pinia**: Intuitive state management.
- **Tailwind CSS**: Utility-first CSS framework.
- **Lucide Icons**: Clean and consistent icons.

## Getting Started

### Project Setup

```sh
npm install
```

### Compile and Hot-Reload for Development

```sh
npm run dev
```

### Compile and Minify for Production

```sh
npm run build
```
